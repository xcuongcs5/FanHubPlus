# FanHub Smart Contracts

**Stack:** Solidity / Hardhat / Ethers.js  
**Network:** Polygon L2 (Amoy Testnet → Mainnet)  
**Standards:** ERC-721 / ERC-1155

## Features
- NFT Event Ticket minting with tier metadata (VIP, Standard, Early-bird)
- Anti-scalping secondary market price cap enforcement
- Creator royalty auto-split on resale
- On-chain ownership verification for QR check-in

## Setup

```bash
npm install
npx hardhat compile
npx hardhat test
```
